## 服务器租赁费用通常由哪几项组成

一台 VPS 的账单一般包含五块：套餐月费、超流量费用、额外 IP、付费增值服务，以及一次性操作费。多数人只算第一块，后四块在正常使用时通常为零，但碰到时确实会出现在账单上。

**套餐月费**覆盖 vCPU、内存、NVMe 系统盘、月度流量配额和端口速率这几项打包资源，也是唯一以固定周期扣款的费用。

**超流量**在 GoMami 这里按 $0.06/GB 计；不想按量扣，也可以单独买流量包，100GB $6、1TB $60、10TB $600，折算单价一致。

**额外 IP** 是 $10/个。普通 VPS 套餐默认 1 个 IPv4，Forge 独立服务器每台最多加到 4 个。

**高级 DDoS 清洗**属于付费附加项。所有实例默认带尽力而为的防护，600 Gbps 那档需要额外购买，官网没有公开标价，得开工单问。

**实例转让**（Push Transfer）$10/次，人工处理，24 小时内完成。把机器转给同事或客户时才会用到。

对只用单 IP、流量不超、也不折腾转让的中小站点，这五项里有四项长期是零。真正需要盯的是月费和流量。
